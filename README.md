# نيون سيتي — لعبة عالم مفتوح (مستوحاة من GTA)

لعبة ثلاثية الأبعاد تعمل في المتصفح بـ Three.js، بدون أي ملفات خارجية.

## التشغيل
- **الأسهل:** افتح `dist/neon-city.html` بالنقر المزدوج.
- **للتطوير:** `npm start` ثم افتح `http://localhost:8000` (و`npm run build` لإعادة توليد الملف المستقل).

## الرسوميات
سماء فيزيائية مع غروب وسحب ونجوم وقمر، وانعكاسات حقيقية على الشوارع المبللة، وإضاءة ليلية بنيون ومصابيح، وظلال عالية الدقة، ومعالجة سينمائية للصورة (AO وتوهج وتدرج لوني وحبيبات وضبابية حركة)، ومطر، وسيارات بطلاء لامع وعجلات تدور وآثار انزلاق.

## المميزات
- مدينة 10×10 بلوكات: ناطحات سحاب، حدائق، شاطئ ومحيط، أضواء نيون، دورة نهار وليل.
- مشي/جري/قفز، وسرقة أي سيارة (6 أنواع: سيدان، سبورت، دفع رباعي، فان، تاكسي، شرطة) بفيزياء انجراف وأضرار وانفجارات.
- مشاة وسيارات مرور بذكاء اصطناعي، يهربون عند إطلاق النار.
- نظام مطلوبية بـ 5 نجوم: دوريات، شرطة راجلة، مطاردات.
- أسلحة: قبضة، مسدس، رشاش، بندقية صيد (من متجر الأسلحة).
- مهمات: توصيل طرد، تصفية عصابة، سباق شوارع.
- خريطة مصغرة، راديو سينثويف مولّد برمجياً، مؤثرات صوتية.

## التحكم
| الفعل | المفتاح |
|---|---|
| حركة / جري | WASD / Shift |
| قفز / فرامل اليد | Space |
| ركوب / نزول | F |
| إطلاق / تصويب | زر الفأرة الأيسر / الأيمن |
| تبديل السلاح | 1-4 أو العجلة |
| منبّه / موسيقى | H / M |
| جودة الرسوميات | G (4 مستويات، وتنخفض تلقائياً عند ضعف الأداء) |
| مطر / صحو | R |

الدوائر على الخريطة: 🟡 مهمة · 🟠 متجر أسلحة · 🟢 ورشة طلاء (تُسقط النجوم) · 🔴 مستشفى.
